# ReadEcho Pro

智能阅读助手 - 基于 PyQt6 的 EPUB 电子书阅读与 AI 笔记工具

## 功能

- EPUB 电子书导入和阅读
- AI 书籍总结、思维导图（分段处理，支持大文件）
- 多模型支持（DeepSeek / Ollama）
- 语音转文字（Whisper）
- 书架管理和笔记编辑

## 快速开始

```bash
# 双击启动（推荐）
start.bat

# 使用虚拟环境启动（需要语音功能时）
start.bat --venv
```
